# Deposition from a random walk

Converts airborne mass from
[`random_walk()`](https://matthewkling.github.io/windscape/reference/random_walk.md)
into deposition per time step, `lambda * airborne`, where lambda is the
per-step decay fraction implied by `half_life`. For a stream-mode walk
this is steady-state deposition per step; for a pulse-mode walk it is
the deposition during each recorded time step.

## Usage

``` r
rw_deposition(x)
```

## Arguments

- x:

  A `wind_walk` generated by
  [`random_walk()`](https://matthewkling.github.io/windscape/reference/random_walk.md).

## Value

A SpatRaster of deposition per time step, with one layer per layer of
`x`.
